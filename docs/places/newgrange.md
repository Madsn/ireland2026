# Newgrange / Brú na Bóinne

UNESCO World Heritage Site. Neolithic passage tomb built ~3200 BC — older than Stonehenge and the Pyramids. The complex includes Newgrange, Knowth, and Dowth.

## Key Facts

| Field | Value |
|-------|-------|
| Access | Via **Brú na Bóinne Visitor Centre** only — cannot walk to monuments independently |
| Visits | Shuttle bus from visitor centre |
| Booking | **Must pre-book in summer** — sells out weeks in advance |
| Time needed | 2.5–3 hours for the full visit |
| Best ticket | Combined Newgrange + Knowth for best value |
| Map | [Google Maps](https://maps.google.com/?q=Bru+na+Boinne+Visitor+Centre+Donore+Ireland) |

## Notes

- Book the combined ticket (Newgrange + Knowth) for best value
- The famous winter solstice sunrise alignment (Dec 21) is not relevant in July but worth mentioning to kids
- Check OPW website for current opening hours and booking
